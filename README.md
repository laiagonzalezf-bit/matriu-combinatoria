# Matriu combinatòria

Eina per dissenyar activitats de llenguatge musical combinant competència, modalitat, format, agrupament, paràmetre, palanca de complexitat i escriptura.

Materials de l'assignatura *Didàctica del Llenguatge i l'Expressió Musical II* (ESMUC).
